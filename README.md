# 다운로드 폴더 정리 도구

다운로드 폴더의 파일들을 자동으로 카테고리별로 정리해주는 데스크탑 애플리케이션입니다.

## 주요 기능

- **자동 파일 분류**: 파일 확장자에 따라 8가지 카테고리로 자동 분류
  - 이미지 (jpg, png, gif, svg 등)
  - 문서 (pdf, doc, xls, ppt 등)
  - 비디오 (mp4, avi, mkv 등)
  - 오디오 (mp3, wav, flac 등)
  - 압축파일 (zip, rar, 7z 등)
  - 프로그램 (exe, dmg, deb 등)
  - 코드 (js, py, java, html 등)
  - 기타 (나머지 모든 파일)

- **미리보기 기능**: 정리하기 전에 어떤 파일들이 어떻게 분류될지 확인
- **안전한 파일 처리**: 같은 이름의 파일이 있으면 자동으로 번호 추가
- **설정 옵션**:
  - 날짜별 하위 폴더 생성
  - 숨김 파일 건너뛰기

- **직관적인 UI**: 깔끔하고 사용하기 쉬운 인터페이스

## 설치 방법

1. 저장소 클론:
```bash
git clone <repository-url>
cd downloads-organizer
```

2. 의존성 설치:
```bash
npm install
```

## 사용 방법

1. 애플리케이션 실행:
```bash
npm start
```

2. 개발 모드로 실행 (DevTools 포함):
```bash
npm run dev
```

## 사용 가이드

1. **폴더 선택**:
   - "다운로드 폴더 사용" 버튼을 클릭하여 기본 다운로드 폴더 선택
   - 또는 "폴더 선택" 버튼을 클릭하여 원하는 폴더 선택

2. **미리보기**:
   - 선택한 폴더의 파일들이 카테고리별로 분류되어 표시됩니다
   - 각 카테고리에 몇 개의 파일이 포함되는지 확인 가능

3. **정리 시작**:
   - "정리 시작" 버튼을 클릭하여 파일 정리 실행
   - 파일들이 카테고리별 폴더로 자동 이동

4. **결과 확인**:
   - 정리 완료 후 성공/실패/건너뛴 파일 수 확인
   - 각 카테고리로 이동된 파일 목록 확인

## 기술 스택

- **Electron**: 크로스 플랫폼 데스크탑 애플리케이션 프레임워크
- **Node.js**: 파일 시스템 작업
- **HTML/CSS/JavaScript**: UI 구현

## 프로젝트 구조

```
downloads-organizer/
├── main.js              # Electron 메인 프로세스
├── preload.js           # IPC 통신 설정
├── package.json         # 프로젝트 설정
├── organizer/
│   └── fileOrganizer.js # 파일 정리 로직
└── renderer/
    ├── index.html       # 메인 UI
    ├── styles.css       # 스타일시트
    └── renderer.js      # UI 로직
```

## 주의사항

- 파일 정리 작업은 되돌릴 수 없으므로 신중하게 사용하세요
- 중요한 파일이 있는 폴더는 미리 백업하는 것을 권장합니다
- 시스템 폴더나 프로그램 폴더는 정리하지 마세요
